# 大肥鱼桌宠

<img src="assets/app-icon-preview.png" width="200" alt="大肥鱼">

一个会把你的桌面变成大肥鱼主题的 Windows 小玩具。

点下「允许并继续」，桌面背景和图标一起变身；敲敲键盘、点点鼠标，还会响起熟悉的 Windows 提示音。三分钟后自动退出，也可以随时按 **Alt+F4** 结束。

## 下载

**[下载最新版](https://github.com/Taimai07/big-fat-fish-desktop-pet/releases/latest)**

下载后直接双击，不用安装，也不用另外下载图片。支持 Windows 10 / 11。

## 怎么玩

1. 双击打开，阅读提示后允许采集桌面信息。
2. 看大肥鱼铺满桌面，试试键盘、点击和滚轮。
3. 按 **Alt+F4** 提前结束，或者等三分钟自动退出。

运行时会采集桌面画面和图标信息，仅在本机内存中使用，不保存、不上传；真实文件和桌面图标不会被改动。
