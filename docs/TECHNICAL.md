# 技术说明

拒绝立即退出。允许后，程序暂时显示桌面、读取公开桌面界面的图标数量/位置/显示名称，并对所有连接显示器各采集一帧画面。截图用于任务栏副本的外观和小图标替换；桌面图标对应依靠界面只读几何信息。

**退出：**效果显示三分钟后自动关闭所有显示层；随时可按 **Alt+F4** 或通过任务栏正常关闭。效果画面不设置退出按钮，Esc 不退出；授权阶段可取消；同意后不显示准备弹窗，直接进入效果画面。没有输入锁定，其他应用切换、任务管理器及系统安全界面可正常使用。到时清理与手动关闭走相同流程，并尝试恢复此前最小化的窗口。

按键、点击和滚轮在本程序窗口内播放 Windows 提示音，移动鼠标不响，声音受系统音量及声音方案影响。Alt 本身不触发声音，Alt+F4 正常退出时也不触发提示音。

## 数据和权限

- 截图与图标信息只在本机内存使用，应用没有截图/名称导出、上传、遥测或网络功能。
- 不扫描文件夹，不读取文件内容、路径、注册表、图标布局系统数据库或其他进程内存。
- 不修改真实桌面、文件、图标、壁纸、任务栏或系统字体设置。
- 不提权，不自启，不驻留，不加全局键鼠钩子，不模拟输入，不混淆加壳或绕过安全防护。
- 只读 Windows 公共显示接口获取图标字体和各屏 DPI，按 GDI 文字排版绘制名称。

Windows 自身的交换区或崩溃转储不受应用控制；“仅内存”描述的是本应用的数据处理方式。

## 已知限制

只支持能够提供完整公开图标列表的 Explorer 桌面；接口不可用、枚举不完整或超时就停止，不靠猜测补图标。某些系统只提供整体项目区域，图像与文字分界仍可能不够精确。任务栏小图标使用像素检测，透明或特殊布局可能误判。字体跟随 Windows 图标标签设置，但主题阴影及个别长名称换行不保证逐像素相同。

使用普通无边框全屏窗口，不独占显示、不强制置顶。特殊置顶程序、通知或无法最小化的窗口可能盖到画面中。显示桌面/恢复窗口仍可能有系统动画；恢复失败会提示手动恢复。

## 源码构建

在 Windows PowerShell 运行：

```powershell
.\build.ps1
.\tests\test.ps1
```

编译使用系统自带 .NET Framework C# 编译器，无需联网安装依赖。输出 `dist/大肥鱼桌宠.exe`，背景、小角色和程序图标均内嵌，无运行时解压。

纯模拟预览（不截取真实屏幕，也不最小化其他应用）：

```powershell
& .\dist\大肥鱼桌宠.exe --simulate
```

`--simulate-windowed` 为窗口模拟。两种模拟也会在三分钟后退出。测试只生成合成画面/应用控件截图，不运行真实采集路径。公共仓库不附带私人原参考截图，因此历史原图对照测试会明确跳过；其他可移植测试仍运行。

## 发布新版本

发行文件统一放在 GitHub Releases，每个版本保留独立版本号、更新说明、EXE 和 SHA256 校验文件，不覆盖旧版。从 0.7.2 起，Windows GitHub Actions 直接运行 `build.ps1` 和 `tests/test.ps1`，使用该次源码编译出的 EXE；不再将仓库内预编译的 `downloads/` 文件作为新版本发行输入。

维护者更新源代码版本号和 `RELEASE_NOTES.md` 后，推送匹配的 `vX.Y.Z` 标签或手动运行 Publish versioned Windows release。修改工作流或 `publishing/` 也会触发发布验证。流程检查版本、受控应用测试和发布契约，再把构建产物整理成 `release/BigFatFish.exe`，按相同文件名生成 `SHA256SUMS.txt`。Release 说明附源码提交和构建日志链接，日志记录编译器版本。已发布版本文件不一致时停止，不覆盖；旧编译器的时间戳/MVID 可能使相同源码的重新编译哈希不同，需要修正发行内容时使用新版本号。

0.7.2 本地公共源码通过 92 项受控检查和 6 项发布契约检查；新增覆盖先按 Alt 再按 F4、左右 Alt 与命令预处理路径，以及正确哈希配错文件名时拒绝发布。没有自动采集真实桌面进行测试。

`downloads/` 保留历史版本兼容用途。0.7.1 的校验文件使用旧中文文件名，与该版 Release 的 `BigFatFish.exe` 名称不同；按旧文件名核验需要先改名，该历史发行不覆盖。

代码许可证与图片授权分别处理；目前尚未添加代码 LICENSE，待维护者选定。发布程序未签名，CI 构建并不替代代码签名，也不保证系统或安全软件不会提示。
